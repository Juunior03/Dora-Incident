# Références EBA — registre d'information DORA

Fichiers publiés par l'EBA sur la page « Preparation for DORA application »
(https://www.eba.europa.eu/activities/direct-supervision-and-oversight/digital-operational-resilience-act/preparation-dora-application),
téléchargés le 30/09/2026. Ils servent de référence pour les listes de valeurs, l'export
et le rapport d'anomalies du module Registre.

| Fichier | Contenu |
|---|---|
| `listes_valeurs_DPM4_2025-03-03.xlsx` | Codes EBA de toutes les listes déroulantes, par modèle (DPM 4.0) |
| `activites_autorisees_DPM4.xlsx` | Activités autorisées (B_06.01.0020) par type d'entité, avec leurs codes |
| `controles_et_regles_validation_2025-04-28.xlsx` | Contrôles techniques et règles de validation appliqués à la remise |
| `maquettes_annotees_DORA_4.0.xlsx` | Maquettes annotées des modèles B_01.01 à B_99.01 (codes de colonnes de la taxonomie) |

À noter : la taxonomie DPM 4.0 numérote les colonnes de B_06.01 de 0010 à 0100, alors que le
règlement d'exécution (UE) 2024/2956 va jusqu'à 0110 (pas de colonne 0050). Les fichiers remis
et les retours des autorités utilisent la numérotation de la taxonomie.

Vérifier avant chaque campagne de remise que ces fichiers sont toujours ceux en vigueur.
